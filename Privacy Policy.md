Privacy Policy for Tűzgömb

1. Architecture and Data Collection
Tűzgömb operates as a pure client application. The developer of this application does not operate any backend servers and does not collect, transmit, store, or process any personal data, device identifiers, or IP addresses.

3. User-Provided Servers (BYOS)
The application requires users to manually input a destination server IP address or domain. When a connection is established, the application transmits a locally generated, ephemeral Device ID and a user-provided nickname to that specific, third-party server to maintain session state and app functionality.

4. Third-Party Data Processing and Data Deletion
Because data transmission occurs strictly between the local client and the server explicitly provided by the user, the developer has no access to, control over, or logs of this data. The developer cannot delete data from third-party servers. Any requests regarding data access, logging practices, or data deletion must be directed to the administrator of the specific server the user connected to.
